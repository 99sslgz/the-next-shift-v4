# The Next Shift

**[Play the game](https://99sslgz.github.io/the-next-shift-v4/)**

Team 12's interactive game about autonomous mobile robot monitoring, privacy, safety, and fair treatment at work. Follow Tim, Priya, and Tom through three stories with opening scenes, **five decisions each**, and **20 ending families**. Choices change the warehouse and carry into later chapters.

## Run locally

With Node.js 20+, double-click **Start-Next-Shift.cmd** and keep its window open. No packages or build step are required.

## Development

Edit `dist/`. Check changes with `npm test` and `npm run check`. After editing `dist/index.html`, run `npm run prepare:pages`.

GitHub Pages publishes automatically from `main`. Progress stays in the player's browser. All scenarios and data are fictional; there are no accounts, analytics, or response uploads.
